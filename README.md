# Mor, essa é pra você 💙

Um site romântico responsivo, feito com HTML, CSS e JavaScript puro. Não precisa instalar frameworks.

## 1. Abrir no VS Code

1. Baixe e extraia o arquivo ZIP.
2. Abra o VS Code.
3. Clique em **File > Open Folder** (ou **Arquivo > Abrir Pasta**) e escolha a pasta `mor-essa-e-pra-voce`.
4. Abra `index.html`.
5. Para testar com mais facilidade, instale a extensão **Live Server** no VS Code, clique com o botão direito em `index.html` e selecione **Open with Live Server**. Também pode abrir o `index.html` diretamente no navegador.

## 2. Personalizar o texto

Abra `index.html` e procure os textos entre as tags, como `Mor, essa é` ou `Às vezes eu fico pensando`. Substitua pelas suas palavras, sem apagar as tags HTML ao redor.

## 3. Como publicar gratuitamente com GitHub Pages

Você pode publicar os arquivos estáticos usando o GitHub Pages:

1. Crie/entre na sua conta em https://github.com/.
2. Crie um repositório novo, por exemplo `site-da-mor`.
3. Envie os arquivos `index.html`, `style.css`, `script.js`. O `index.html` deve ficar na raiz do repositório.
4. No repositório, abra **Settings > Pages**.
5. Em **Build and deployment**, escolha **Deploy from a branch**; selecione a branch `main` e a pasta `/(root)`, depois salve.
6. Aguarde a publicação. O GitHub mostrará um endereço parecido com `https://SEU-USUARIO.github.io/site-da-mor/`. Copie o endereço que aparecer na sua conta e mande para a Mor.

Os nomes exatos dos menus podem mudar. O repositório público torna os arquivos visíveis a qualquer pessoa. Como o site é público, não coloque dados pessoais sensíveis nem fotos que vocês não queiram compartilhar.

## 4. O que já funciona

- Envelope de abertura animado.
- Layout adaptado para celular e computador.
- Animações de entrada conforme você rola a página.
- Carta em janela modal, que pode ser fechada com o botão ou com `Esc`.
- Cartões de motivos do amor que viram ao tocar.
- Botão que revela uma mensagem secreta.
- Botão de música com seleção de áudio local.
- Respeita a preferência do dispositivo por movimento reduzido.

## 5. Antes de mandar o link

- Teste o site no celular.
- Troque os textos por palavras que soem como você.
- - Teste os botões e a música.
- Confira que você está confortável em publicar as fotos e mensagens.
